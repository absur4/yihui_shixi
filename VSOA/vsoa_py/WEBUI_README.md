# VSOA 可视化通信性能实验台

这是一层 **Web UI 封装**，不会重新实现 VSOA 测试，也不会生成模拟性能数据。后端逐项调用项目根目录现有的 15 个 `test_*.py`，结果仍由原测试脚本产生。

## 使用

把本补丁中的 `webui/`、`run_webui.bat`、`run_webui.ps1` 放到原 `vsoa_py` 根目录，与 `test_latency.py`、`run_all.py` 同级。

Windows 双击：

```text
run_webui.bat
```

默认打开：

```text
http://127.0.0.1:8765/
```

不需要新增 FastAPI/Flask 依赖；Web 服务器使用 Python 标准库。测试本身仍要求原项目中的 `vsoa==1.0.4` 和 `psutil` 能正常导入。

## 页面能力

- 左侧：选择 15 个测试项、运行范围和原测试参数。
- 顶部：根据当前测试动态显示 4 个 KPI。
- 中部：延迟/抖动/内存等显示真实样本曲线；吞吐/CPU/启动/丢包恢复显示真实指标柱状图。
- 底部：统一指标、实时运行日志。
- 测试动画：按当前测试切换 RPC、发现、发布订阅、丢包/补发等动画。
- 怎么测试的：展示每一项测试的真实调用流程、输出字段和证据边界。
- 原始 JSON：显示原测试脚本生成的完整结果。
- 对应源码：直接从当前项目读取 `test_*.py` 及相关 `bench/*.py` 源码。
- 历史结果：保存在 `results/webui/<job_id>/`，可导出 `summary.json`。
- 支持重复运行、功能 8 项、性能 7 项或全部 15 项批量顺序测试。

## 重要边界

当前 15 个原始脚本的拓扑是 **本机 IPv4 loopback**。页面中的“多机协同”故意置灰，避免把尚未实现的远端测试误标为可用。

原脚本把 `payload_bytes` 限制为最多 60000 B。因此界面虽然保留 1 MiB 作为统一中间件 UI 的视觉选项，但会阻止直接提交；VSOA 当前测试请使用 60000 B 或更小。

丢包恢复测试的显式缺失 ID 补发与去重属于测试 harness，不是 VSOA 原生可靠性保证。网页仍会把这个边界显示在“怎么测试的”页签中。
